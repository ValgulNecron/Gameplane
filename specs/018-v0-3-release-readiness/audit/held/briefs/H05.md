Held brief (OD-019). This file lives under `audit/held/` and is never committed.

- **Branch:** `fix/018-harden-release-signing`
- **Base:** `origin/master` (scouted at `61f50265`)
- **Blocked:** no, for the workflow commit. D16's repository settings are the maintainer's job and are listed in HELD NOTES. The workflow change is safe to merge before them: a job naming an environment that doesn't exist yet gets it auto-created with no policy, and repository-scoped secrets stay readable until the maintainer moves them.
- **What changes (workflow files and two docs only):**
  1. The signing-key check runs before any build or push step in every image job.
  2. Images are pushed **by digest only** (`push-by-digest=true`, no tags), signed, and verified. Only then is each tag attached with `oras tag`, and the step checks that every tag resolves to the signed digest.
  3. `release.yaml`'s image matrix gets `fail-fast: false`.
  4. Every job that uses `COSIGN_*` declares `environment: release-signing`. In `images.yaml`, which also runs on pull requests, the environment is conditional, so PR runs take none.
  5. `docs/contributing.md` and `docs/module-authoring.md` describe the environment, the sign-then-tag order and the re-run policy. `CHANGELOG.md` gets one line.
- **Not changed (see HELD NOTES):** the chart push (`helm push` always tags), the module bundles (`modules/build.sh` is in the submodule repo), and `release.yaml`'s `timeout-minutes` (a separate public follow-up).

          if [ -f cosign.pub ] && ! cmp -s cosign.pub "$RUNNER_TEMP/cosign.pub"; then
            echo "::error::committed cosign.pub does not match COSIGN_PRIVATE_KEY — update the published key"
            exit 1
          fi
      # Attach the release tags only now that the digest carries a verified
      # signature. `oras tag` points each tag at the existing manifest without
      # rewriting it; the loop confirms every tag resolves to the signed digest.
      # A leg that fails before this step leaves only an untagged digest, so
      # re-running the failed jobs is always safe.
      - name: install oras
        uses: oras-project/setup-oras@1d808f7d7f6995cc68b7bf507bfe5c5446e1dc9d # v2.0.1
      - name: attach release tags to the signed digest
        env:
          IMAGE: ${{ steps.image.outputs.name }}
          DIGEST: ${{ steps.build.outputs.digest }}
          TAGS: ${{ steps.meta.outputs.tags }}
        run: |
          set -euo pipefail
          mapfile -t refs < <(printf '%s\n' "$TAGS" | sed '/^[[:space:]]*$/d')
          if [ "${#refs[@]}" -eq 0 ]; then
            echo "::error::no release tags were computed for ${IMAGE}"
            exit 1
          fi
          tags=()
          for r in "${refs[@]}"; do
            if [ "${r%:*}" != "$IMAGE" ]; then
              echo "::error::${r} is not a tag of ${IMAGE}"
              exit 1
            fi
            tags+=("${r##*:}")
          done
          oras tag "${IMAGE}@${DIGEST}" "${tags[@]}"
          for t in "${tags[@]}"; do
            got="$(oras resolve "${IMAGE}:${t}")"
            if [ "$got" != "$DIGEST" ]; then
              echo "::error::${IMAGE}:${t} resolves to ${got}, not the signed digest ${DIGEST}"
              exit 1
            fi
          done
